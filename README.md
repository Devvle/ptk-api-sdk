# PromptTK SDK

This is the PromptTK API SDK, which provides a convenient way to interact with the PromptTK API. It is designed to simplify the process of making requests and handling responses from the API.

## Current Version

The current version of the SDK is `0.0.1`. This version includes basic functionality for making requests to the API and handling responses. Currently you can verify your API key (free) and request a prompt (paid).

Full api documentation can be found at [docs.prompttk.com](https://docs.prompttk.com).
